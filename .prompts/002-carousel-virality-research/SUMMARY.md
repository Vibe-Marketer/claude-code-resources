# Carousel Virality Research Summary

**6 carousel formulas + 9 visual rules + the key insight: virality and conversion require fundamentally different structures—and no AI tool has cracked this yet.**

## Key Findings

1. **The curiosity gap is the core psychological engine**: Carousels that create information gaps (tease on slide 1, reveal on slide 3/5/final) generate compulsive swiping. The AI must architect "revelation sequences," not just create slides.

2. **Slides 1-3 are a unit, not individuals**: Exit rate on slide 1 is 23.8%, but drops to ~13% by slide 4. The first three slides must work together as a "hook sequence"—stop scroll, confirm relevance, commit viewer.

3. **Text-image separation is highly viable**: Generate text content first (optimizing for persuasion psychology), then apply visual templates, then combine with smart text placement. This decoupling enables each component to be optimized independently.

## Carousel Formulas Discovered

- **The Educational Tutorial**: Step-by-step value delivery optimized for saves (9 slides)
- **The Myth Buster**: Contrarian takes that engage defensiveness, optimized for shares (9 slides)
- **The Transformation Story**: Before/after narrative for trust-building and conversions (9 slides)
- **The List Value-Bomb**: Numbered resource lists optimized for saves and authority (9 slides)
- **The Quiz Engagement**: Interactive format driving comments and reach (9 slides)
- **The Soft-Sell Educator**: Educational content with natural offer integration (9 slides)

## Text-Image Separation Verdict

**HIGHLY VIABLE.** Research and existing tool patterns validate this approach. Benefits: (1) Text optimized purely for persuasion, (2) Images optimized for visual consistency, (3) Smart combination with contrast detection and safe-zone mapping. Recommended architecture: 3-stage pipeline (Content Generation -> Visual Generation -> Rendering).

## Critical Recommendations

1. **Implement goal-based generation**: "Viral" vs "Conversion" modes producing different structures
2. **Architect curiosity gap mapping**: AI must plan reveal arc before generating content
3. **Enforce first-slide optimization**: 8-12 words max, 70-100pt text, squint-test compliance
4. **Build hook sequence logic**: Slides 1-3 generated as interdependent unit
5. **Auto-inject micro-prompts**: "Swipe for more" increases swipe-through 15-30%

## Visual Rules (Implementable Specs)

| Rule | Specification |
|------|---------------|
| First slide typography | 70-100pt minimum, 8-12 words max |
| Contrast | 4.5:1 minimum ratio |
| Text density | 10-15 words per slide max |
| Aspect ratio | 4:5 portrait (1080x1350px) |
| Font limit | 2-3 fonts with clear hierarchy |
| Safe zones | Text in top 60%, 40px+ margins |
| Swipe indicators | On slides 1-3, bottom-right, 20-30% opacity |
